Install

Get OpenKara running with the least friction.

The lightest path is to install a release build. If you want to contribute or inspect the stack, build it locally with Node, pnpm, Rust, and the Tauri prerequisites.

Recommended

Install from GitHub Releases

  • macOS Apple Silicon: `.dmg`
  • macOS Intel: `.dmg`
  • Windows: `.exe` installer
  • Linux: `.AppImage`

On first launch, OpenKara prompts you to create a karaoke library and download the AI model.

Open releases

For contributors

Build from source

  • Node.js 20+
  • pnpm 10+
  • Rust stable toolchain
  • Tauri 2 platform prerequisites
git clone https://github.com/thedavidweng/OpenKara.git
cd OpenKara
pnpm install
./scripts/setup.sh
pnpm tauri dev
