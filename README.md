# Errore 404: Sprint Non Trovato!

A 2D runner where the environment constantly shifts. You race on a grid, with rows and columns moving and cells moving down, rising or disappearing unpredictably. The terrain evolves, triggering obstacles and bugs that disrupt the race.

Survive the longest or reach the exit before others. Collect bonuses/maluses while avoiding traps.

4 players (humans and/or bots).
