🚀 What Makes Lopus Unique?

Lopus was created to solve a common Linux frustration: having to jump between ten different tools for file management, mounting cloud drives, editing audio tags, bulk-renaming files, and managing network shares. Lopus brings everything together into one unified, responsive workspace:

    Asynchronous & Non-Blocking: Designed specifically to handle slow network mounts (rclone, NFS, SMB) or heavy directories without ever freezing the UI.

    All-in-One Powerhouse: Instead of just browsing files, it integrates a dedicated Mp3tag-style music tag editor, a bulk file renamer, an archive manager, and automated disk/mount management.

    Extensible via Python: Drop a .py script into your configuration folder, and it instantly becomes a native menu option or toolbar button.

    Lightweight & Native: Built purely on Python and PyQt6—no bloated Electron frameworks or massive memory footprints.

🛠 Key Features

    Dual-Pane & Tabs: Independent navigation with drag-and-drop tab support, pinned tabs, and persistent layouts.

    Cloud & Network Integration (rclone & Shares): Seamlessly mount and manage OneDrive, Google Drive, SMB/NFS shares, and local drives with zero terminal syntax required.

    Advanced Media Tag Editor (tageditor.py): A built-in spreadsheet-like grid for music tags, supporting online lookups via MusicBrainz/Discogs, batch cover art embedding, and automated renaming format strings.

    Bulk Renamer (renamer.py): Bulk Rename Utility-style live preview table for handling mass file renames safely.

    Granular Permissions & Root Actions: Full chmod/chown octal control, secure root opening (pkexec), and checksum generation (SHA-256).

    Smart Customization: Deep UI theming, custom file-type color coding, compact views, and file grouping by type, date, or size.
