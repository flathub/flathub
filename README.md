com.automattic.Beeeper
======================

This is a Flatpak-ready packaging of Automattic's Beeper client.

It is NOT official, and NOT endorsed by Automattic. Please report Flatpak-related bugs to this repository with the application. 

We would recommend if you experience bugs with Beeper, you try to reproduce with the official packaging, and if that fails, then report it to Automattic. If it is not reproducible with the official packaging, then please report it to the Flatpak.
